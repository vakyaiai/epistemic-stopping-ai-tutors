# Experimental Protocol

The study used ten scripted mathematics-learning histories.

Each history was tested under three final-answer conditions:

- CN: Correct-neutral
- CU: Correct-uncertain
- IN: Incorrect-neutral

Each condition was repeated twice across three models,
producing 180 analysed responses.

The execution notebooks contain the implemented
experimental prompts and procedures.

The Epistemic Stopping Scorecard (ESS) evaluates
correctness recognition, conversational support,
and instructional stopping.

Coding and adjudication details are documented
in the results archive.
